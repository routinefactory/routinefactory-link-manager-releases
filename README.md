# 루틴팩토리 링크 관리자

워드프레스에 설치하는 다중 링크 허브·상품 번호·묶음 관리자입니다. 데이터는 각 사이트의 워드프레스 DB에 저장합니다.

[최신 설치 ZIP과 업데이트 안내](https://github.com/routinefactory/routinefactory-link-manager-releases/releases/latest)

워드프레스 관리자 → 플러그인 → 새 플러그인 추가 → 플러그인 업로드에서 ZIP을 설치합니다. WordPress6.6 이상과 PHP8.1 이상이 필요합니다. 처음에는 데이터가 비어 있습니다.

0.2.0부터 서명된 GitHub 배포 정보와 ZIP 해시·호환성을 확인하는 업데이트 기능을 제공합니다. 자동 설치는 기본 꺼짐이며 플러그인 설정에서 켤 수 있습니다. 0.1.x는 처음 한 번 ZIP으로 수동 업데이트하세요.

0.2.1부터 「도움말 · API」에서 전체 기능과 API를 검색하고, 사이트 주소가 반영된 설명서(.md)와 OpenAPI 명세(.json)를 저장할 수 있습니다. 외부 AI 에이전트에는 문서를 전달하고 실제 API 키는 실행 환경에 별도로 설정하세요.

업데이트 전 호스팅의 DB·미디어 백업을 유지하세요. 콘텐츠 내보내기는 전체 복원용 백업이 아닙니다. 제거 시 데이터는 보존합니다. 상세 사용법과 제한은 설치 ZIP의 HELP.md/openapi.json/README.md/API.md/CUSTOMIZE.md에서 확인할 수 있습니다.

이 저장소는 공개 설치 패키지와 업데이트 정보 전용입니다. 개발 저장소·개발 기록·개인 설정은 포함하지 않습니다. 공개 ZIP은 설치용 PHP 코드를 포함합니다. 구매·매출 추적과 중앙 라이선스 서버는 사용하지 않습니다.
